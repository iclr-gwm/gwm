How the model and workflow memory work together

Contexts, not just actions

Nodes group embedded interaction-history prefixes. Their short labels here summarize illustrative contexts; they are not literal environment states or internal model activations.

Evidence behind a continuation

Edges record observed successor relations. Stored workflow evidence includes toolsets, outcome associations, support, and examples. The graph shows a schematic subset; it does not display measured probabilities or counts.

Guidance, then execution

Retrieved evidence informs advice before the agent proposes candidates. Selection chooses a candidate before tool execution. Actual tool observations update live history. In the approval example, an authorized reviewer supplies approval. The model diagram offers two illustrative access routes: Model API, or a served model connected through the vLLM Extension. Changing the view makes no real connection.
